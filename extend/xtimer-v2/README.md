# xtimer-v2 — 单轮+红黑树定时器

## 概述

基于**单层时间轮 + 红黑树**的高性能定时器系统。近程定时器 O(1) 入轮触发，远程定时器按 expires 分组存入红黑树，轮槽归零时批量搬入。

## 架构

```
┌─────────────────────────────────────┐
│  Timer                              │
│  ┌──────────────┐  ┌─────────────┐  │
│  │ wheel[256]   │  │ rbTree      │  │
│  │ O(1) 插入/触发│  │ O(log n) 操作│  │
│  │ 近程: <256    │  │ 远程: ≥256   │  │
│  └──────┬───────┘  └──────┬──────┘  │
│         │                 │         │
│         │  轮槽归零时搬入  │         │
│         └─────────────────┘         │
└─────────────────────────────────────┘
```

## 与 xtimer v1 对比

| 特性 | v1（多层级联） | v2（单轮+树） |
|------|-------------|------------|
| 时间轮层数 | 5层（tv1~tv5） | 1层（256槽） |
| 远程定时器 | 高层轮 + Cascading | 红黑树分组 |
| 插入复杂度 | O(1) 直接入对应层 | O(1) 轮内 / O(log n) 树 |
| 删除复杂度 | O(1) | O(1) 轮内 / O(log n) 树 |
| 内存占用 | 320槽固定 | 256槽 + 树节点 |
| 代码行数 | ~400行 | ~250行 |

## API

```go
// 初始化
timer.Init(tick func() int64, wheelSize int64)

// 添加定时器
timer.After(duration int64, cb func()) *Handle    // 一次性
timer.Every(duration int64, cb func()) *Handle    // 间隔

// 句柄操作
handle.Delete()              // 删除定时器
handle.Reschedule(duration)  // 重新安排
handle.Remain() int64        // 剩余滴答
handle.Valid() bool          // 是否有效

// 驱动 & 查询
timer.Update()               // 驱动时间轮
timer.GetMinExpires() int64  // 最近到期滴答

// 生命周期
timer.Clear()                // 清除所有定时器
timer.PreAlloc(n int)        // 预分配节点
```

## 性能

- 近程定时器（<256滴答）：O(1) 入轮 + O(1) 触发
- 远程定时器（≥256滴答）：O(log n) 红黑树插入 + O(1) 轮内触发（搬入后）
- 压力测试：10000个定时器，200滴答跨度，全部正确触发
